# 🎭 Genshin RPG Bot — Орион

Telegram-бот для чатов с ролевой игрой по мотивам **Genshin Impact**.  
Игрок выбирает персонажа, качается, воюет с боссами, вступает в гильдии, создаёт отношения.

## ✨ Возможности

### 👤 Игрок
- Регистрация и выбор персонажа из 9 регионов Тейвата
- Личный профиль: баланс, смола, репутация, отношения, гильдия
- Смена персонажа через магазин

### 💰 Экономика
- **Монеты** — за активность, квесты, подземелья, боссов
- **Смола** — восстанавливается со временем, тратится на данжи
- **Репутация** — 10 уровней, дают бонусы к заработку и дропу

### 🏛 Гильдия искателей
- 5 подземелий с разными наградами
- Доска занятости (ежедневные квесты)
- Артефакты: 4 слота, 3 редкости, бонусы
- Мировые боссы (ротация каждую субботу)
- Гильдии с казной, составом и боссом

### ❤️ Социальное
- Отношения с уровнями и XP
- Свадьба на 5 уровне
- Усыновление / удочерение
- 50+ взаимодействий в чате (обнять, поцеловать, дать леща...)

### 🎲 Развлечения
- Казино (рулетка, слоты, кости)
- Викторина по Genshin
- Дуэли с ставками
- Кулинария с баффами

### 🛡 Модерация
- Система варнов (3 = мут 24ч)
- `/mute`, `/unmute`
- Защита отдельных пользователей

### 🛠 Надёжность
- Логирование в файл с ротацией
- Мониторинг ошибок через Sentry
- Планировщик задач (APScheduler)
- Docker-контейнер с автоперезапуском
